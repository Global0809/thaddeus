# Thaddeus validation record

This record describes browser and source observations. It does not certify physical-device Safari, thermal behaviour or a universal frame rate.

## Source and assets

- JavaScript syntax checks pass for the brand interface, boot loader, jewellery module, native application, data and support.
- The geometry integrity check validates finite attributes, normalized normals, triangle winding, indices and the gemstone's convex cut/ray intersections.
- All 251 rasters decode. The 249 pre-existing images preserve identical decoded pixels; the two additions are the supporting ring cutout and social-preview JPEG. Provenance is embedded or recorded in companion metadata.
- The nine campaign photographs are supplied images, presented through 18 responsive variants. The main ring is geometry, not a product-image plane.

## Interaction and layout

Bounded desktop and phone checks cover all three perspectives, native camera macros, campaign reveals, nine-image gallery, selection/removal, local enquiry saving/copy/download, ring measurement, keyboard focus, touch gallery swiping, isolated dialog scrolling and native input resumption. Named artwork produces verified 740 × 740, 1200 × 600 and 740 × 1315 PNGs.

Independent review found two layout defects: the moving desktop selector crossed its supporting text, and the floated close control narrowed the phone product grid. Both were corrected and scored resolved in the subsequent 18-capture verdict. The 360px capture waits for native stage and canvas dimensions to settle.

No-JavaScript presentation, unavailable-WebGL recovery and actual WebGL context-loss recovery were exercised. Initial audio requests are deferred until explicit sound opt-in; sound on/off was verified on desktop and phone.

## Extended navigation regression

An initial 32-minute desktop profile completed 85 cycles. The following phone profile exposed a dropped explicit destination; it was not counted as a pass. A non-invasive route trace proved that a native frame could finalize the previous world before the new router tween's first update. The Thaddeus-only fix keeps the transition active while the tween is animating and commits its exact target on completion. Native easing, timing and gesture paths remain.

Post-fix validation completed 30 rapid desktop changes and 77 phone changes across 20.2 phone-profile minutes, with 77 successful real touch-scroll checks. All 107 requested destinations were reached, with no recorded page/HTTP/non-abort request errors or panel/layout failures. The eight active source hashes remained unchanged throughout the final run. The separate release record identifies public verification and the published commit.

Periodic JS-heap/DOM counters do not measure GPU texture memory. Allocated ring instances are not simultaneous visible rings. A phone profile in desktop Chrome is distinct from physical-device testing.

## Commercial scope

This is a jewellery brand/product preview. Pricing, certified specifications, stock, contact destination and checkout remain unconfirmed. Enquiries are explicitly local drafts; nothing is submitted to Thaddeus. Downloads do not post automatically.
